最難関の学会（CORE A*）の採録論文が、どんなテーマを、どのデータで、どう分けて、何で測り、どう確かめているか。その実態と統計学の根拠を引き合わせて、あなたの研究に合う評価手法と、参考にできる論文を返します。いつもの Claude からは MCP で、ターミナルからは CLI で。

返ってくるもの

同じ特性を持つ採録論文の実態と、勧めの根拠。6 つの問いに答えます。

01 データ

どのデータセット・ベンチマークで評価しているか

02 分け方

学習とテストをどう分け、どんな実験を組むか

03 指標

何の指標で測っているか、何を併記すべきか

04 検定

差をどの検定・区間・ばらつきで確かめるか

05 注意

データの性質と検定の食い違い（乖離の規則）と、その根拠の文献

06 実例

その手法を実際に使った採録論文。DOI と原稿を読めるリンクつき

MCP

中心は MCP。
いつもの Claude が、評価の設計者になる。

Claude が原稿やアイディアを読み、研究の特性を選び、Atlas の道具で採録論文の実態と勧めを引きます。拡張機能にデータを同梱しているので、オフラインでも動きます。

MCP を入れる

CLI

# 文から研究の特性の候補を挙げる
node eval-method-atlas.mjs suggest-traits --text "…"

# 特性から、評価の設計ガイドを書き出す
node eval-method-atlas.mjs design-guide \
  --traits t_forecasting,d_time_series,c_nonstationary \
  --md --out guide.md

# 参考にできる論文（DOI と読めるリンク）
node eval-method-atlas.mjs reference-papers \
  --traits t_forecasting,d_time_series --method temporal_split
