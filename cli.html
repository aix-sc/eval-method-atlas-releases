Getting started

はじめかた

  1. 上の eval-method-atlas.mjs をダウンロードします。登録や API キーは要りません。
  2. Node.js 20 以上を用意します（node --version で確認）。
  3. ダウンロードしたフォルダで実行します。初回に公開データ（数 MB）を ~/.eval-method-atlas に取得し、2 回目からはそれを使います。
# 1. アイディアや原稿の文から、研究の特性の候補を挙げる
node eval-method-atlas.mjs suggest-traits --text "工場のセンサーの時系列から、3 日先の故障を予測したい。季節で傾向が変わる。"

# 2. 選んだ特性で、評価の設計ガイドを Markdown に書き出す
node eval-method-atlas.mjs design-guide --traits t_forecasting,d_time_series,c_nonstationary --md --out guide.md

# 3. 原稿の設計を点検する（使っている評価手法・検定の ID を渡す）
node eval-method-atlas.mjs review-design --traits t_forecasting,d_time_series --tests-used random_split

引数は --名前 値 で渡します。配列は a,b,c か JSON。位置引数で特性 ID や言葉を渡すこともできます。出力は JSON（標準出力）で、エラーは標準エラーに出て終了コード 1 になります。--out でファイルに、--refresh でデータを取り直します。ATLAS_DATA で手元のデータのファイルを指定できます。

毎回 node … と打つのが面倒なら、エイリアスを置いてください。

alias atlas="node ~/tools/eval-method-atlas.mjs"

原稿の PDF の文字は、たとえば pdftotext で取り出して渡せます。

pdftotext draft.pdf - | head -c 6000 > draft.txt
node eval-method-atlas.mjs suggest-traits --text "$(cat draft.txt)"

Commands

コマンド

MCP の道具と 1 対 1 に対応しています。各コマンドの引数は node eval-method-atlas.mjs <command> --help で確認できます。

Data

ファイルはどこへ行くか

CLI は公開データを手元で引くだけで、LLM を呼ばず、渡した文をどこにも送りません。通信するのは、初回（と --refresh のとき）に公開データを GitHub から取得するときだけです。

困ったとき

  • command not found: node：Node.js をインストールしてください。
  • データを取得できない：ネットワークを確認するか、リリースから atlas-data.json.gz を落として ATLAS_DATA で指定してください。
  • 「研究の特性 ID ではありません」：find-traits か suggest-traits で ID を探してください。
